# maimai Lab

本地运行的 maimai DX 曲库和成绩工作台。支持地区曲库、曲绘、手动成绩、maimai DX NET HTML 批量导入、B50 以及目标达成率推分。

## 启动

需要 Node.js 20.9 或更新版本，以及首次同步 DXRating 曲库所需的网络连接。

```sh
npm ci
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。默认使用嵌入式 PostgreSQL（PGlite），曲库和成绩保存在项目的 `.data/postgres` 中。启动时自动建表。想连接已有 PostgreSQL 时，把 `.env.example` 复制为 `.env.local`，填写 `DATABASE_URL`，再重启应用。

```sh
npm run typecheck
npm test
npm run build
npm start
```

`dev` 和 `start` 使用同一份本地数据，同一时间只运行一个。运行中通过应用接口读取成绩。需要直接检查嵌入式数据库或备份时，先关闭应用，再复制整个 `.data/postgres` 目录。诊断和恢复操作在副本上进行。脱机可读取已同步的目录和成绩，外部曲绘可能显示占位图。

## 使用

1. 在侧栏选择你的玩家地区。默认北美，各地区成绩分别保存。
2. 在曲库按曲名、别名、曲师或等级搜索。可直接在谱面行录入达成率。
3. 批量导入时，在官方 maimai DX NET 登录并打开按曲目的成绩列表。在浏览器里保存网页源码为 HTML 文件，或者复制源码。可以提供多份页面，自动读取行内难度。预览核对后确认合并。第三方账号绑定不参与此流程。
4. 在「我的 B50」查看带曲绘缩略图的紧凑卡片。宽屏每行五张，上方是 B35，下方是 B15。若自动选中的版本与机台不同，可在页面选择版本。
5. 在「推分」选择目标达成率。每行的涨幅是单独改善该谱面带来的变化，不能直接把多条建议的涨幅相加。

B50 支持自动读取 MaiShift 北美视图的国际服共享样本。在 MaiShift 的 Settings → Developer 签发应用 API Key，将其写入 `.env.local` 的 `MAISHIFT_API_KEY` 后重启。若使用本地纯北美汇总文件，也可在 B50 页手动载入。见[架构和数据说明](docs/architecture.md)。

本地版是单人应用，默认只监听回环地址。多个用户共用一个数据库会共享成绩。
